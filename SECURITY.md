# Security Policy

SpecLedger takes data security, provenance integrity, and code quality seriously.

---

## 🔒 Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

---

## 🚨 Reporting a Vulnerability

If you discover a security vulnerability or potential data leakage risk in SpecLedger:

1. **Do not disclose the issue publicly** via GitHub issues.
2. Please submit a confidential report or contact the maintainer directly via GitHub Security Advisories.
3. Include detailed steps to reproduce the vulnerability, sample inputs, and the affected components.

We will review and respond to reports promptly to investigate and patch confirmed vulnerabilities.
